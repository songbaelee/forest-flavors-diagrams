# Forest Flavors Diagrams

Standalone interactive HTML diagrams for the Forest Flavors / CRS Social Ventures Fund presentation (Innovative Finance team).

Each file is self-contained — no build step, no dependencies. Open directly in a browser, or view live via GitHub Pages once enabled.

## Diagrams

- **diagram8.html** — Impact chain. Four states: baseline (TA to farmers only) → + SMEs → + Lending (CRS-directed) → Market-driven (lender-directed). Badges show the order in which farmers, SMEs, and the lender come into the picture at each stage.

## Live pages

Once GitHub Pages is enabled (Settings → Pages → Deploy from branch → `main` / root), each diagram is reachable at:

`https://[username].github.io/forest-flavors-diagrams/[filename].html`
